# Startup Runway Model

Startup Runway Model helps you estimate cash runway. Everything lives in one workbook.

## What's included
- The workbook: `tracker.xlsx`
- Demo rows: `example-data.csv`

## Setup
Import `categories.csv` into the Categories tab.
Paste in the sample rows and revenue comes to 1,475 in total. With the included sample rows, the Total Cost cell shows 769.
