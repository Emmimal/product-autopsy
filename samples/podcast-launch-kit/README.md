# Podcast Launch Kit

Podcast Launch Kit helps you launch a podcast. Everything lives in one workbook.

## What's included
- The workbook: `tracker.xlsx`
- Demo rows: `example-data.csv`

## Setup
Open monthly-summary.xlsx for the dashboard view.
With the included sample rows, the Total Revenue cell shows 1,775 and the Total Cost cell shows 758.
